# Personal Job-Seeking Website

This folder contains a polished static website designed for the course assignment **“Final Individual Project — Personal Job-Seeking Website”**.

## Files
- `index.html` — main page
- `styles.css` — styling
- `script.js` — interactions
- `resume.pdf` — your resume file linked on the site

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `job-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save. Your site will be published in about 1–3 minutes.

Expected URL format:
`https://YOUR_GITHUB_USERNAME.github.io/job-portfolio/`

## Notes
- Replace `resume.pdf` if you want to swap in a newer resume version later.
- The site is mobile-friendly and uses pure HTML/CSS/JS, so it works directly on GitHub Pages with no build step.
